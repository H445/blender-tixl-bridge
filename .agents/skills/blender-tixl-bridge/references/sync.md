# Sync and verify

Use Blender MCP and the TiXL debug client throughout. Keep generated import data separate from the user-owned home graph and TimeClips.

1. Inspect the current `.blend` path, scene, camera/timeline camera markers, frame range/FPS, collections, `tixl_project_name`, `tixl_worlds`, enabled add-on and saved preferences through MCP. Require a saved source and active camera or camera-bound markers. Without `tixl_worlds`, the active scene is world `main`; otherwise parse its JSON and require unique non-empty names without `/` or `\`, existing collections and contiguous ranges. Runtime animation is sampled at 60 Hz; arbitrary procedural shaders and physical refraction are not exact transfers.
2. Save through MCP, call `bpy.ops.tixl_bridge.sync_saved_blend()`, and read back the filepath and queue result. `FINISHED` means queued. Do not enable `scene.tixl_bridge_autosync` unless requested.
3. Follow `<blend folder>/.tixl_cache/<blend name>/sync_logs/latest.log` to completion. Read `tixl_project.json`, `current_generation.json`, and `cache_publication.active_root(cache)` (including recovery fallback). Inspect its `worlds/manifest.json`, per-world manifests/channels, `camera_timeline.json`, and cache-root generated graph files. Reject missing or mismatched artifacts.
4. Installation changes saved graph paths. If TiXL is open, let the user save editor work and close it before installation; never terminate it automatically. Launch the configured editor with `--debug-server 9042` when it is unavailable and launch is authorized. Verify `getVersion` through `tixl_bridge.call` before proceeding. If no authorized bootstrap/API can complete a step, request the manual step.
5. Capture `getContext` and `getGraphView` before changing the editor. Pause, `openProject(name=...)`, and read `getGraphState(includeDefaults=False)`. Reject `missingChildren`/`missingConnections`. Verify source clips feed global/per-world sequences; per-world time reaches animation scenes; camera, lights, world selection and preloading remain connected; mesh/texture select-replace indices agree. Consult [operators](operators.md) for unfamiliar routes.
6. Pin the final Output target. Set meaningful `timeInSecs`, pump three frames, capture `screenshot(target="output", path=<absolute PNG>)` and a legible `screenshotWindow(region="graph", path=...)`. Sample every world and both sides of cuts. Inspect the images for geometry, camera, lighting, materials and transitions; file existence is insufficient.
7. Inspect `getLogTail(minLevel="warning")`, tracking `latestSeq`, and `getMetrics`. Restore original project/view, selection, output pin, time and playback state after diagnostics; restore playing mode before exact speed. Clear any activity state. Report cache/project paths, evidence and actionable warnings.

For installation or scene manipulation recipes, load [Blender details](blender.md). For unrecognized commands or parameter shapes, load [protocol details](protocol.md) and the generated full inventory before calling them. After structural disk edits to loaded `.t3`/`.t3ui`, save editor work and restart with the debug server; `reload` is insufficient.
